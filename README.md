# 🛡️ 防災全能王 (Disaster Prevention King) - 互動式防災教育遊戲

這是一個專為國小三、四年級學生設計的互動式 Web 教學工具。透過模擬「地震、颱風、火災」以及「終極挑戰」四大任務情境，引導學生在沉浸式的視覺特效中運用正確的防災知識。本專案特別強化了**錯題檢討機制**，幫助學生在闖關過程中落實知識訂正。

## 🌟 核心特色

-   **完整題庫**：
1.  內建 175 題精心設計的題目（地震 50 題、颱風 50 題、火災 50 題、進階魔王題 25 題），涵蓋台灣國小四年級自然科考點。
2.  題目內容對應台灣國小自然與生活科技、社會領域之防災考點。
-   **沉浸式視覺特效**：
1.  **地震關卡**：具備畫面震動 (Gentle Quake) 效果，強化臨場感。
2.  **颱風關卡**：畫面動態風力搖擺特效。
3.  **火災關卡**：啟用全螢幕濃煙濾鏡 (Smoke Overlay) 與火光律動效果。
-   **錯題紅字標示系統(Critical Feature)**：
1.  在結算畫面中，系統會自動比對學生紀錄，將**答錯的題目以紅字標示 (X)**。
2.  同時在錯題下方對照顯示「正確做法」，方便學生進行紙本學習單抄寫與檢討。
-   **高度隨機與動態化**：
1.  基礎關卡隨機抽取 3 題，魔王關抽取 1 題。
2.  所有選項順序皆為隨機打亂，防止學生記憶答案位置。

## 📖 教學考點涵蓋
1.  **地震應變**：趴下、掩護、穩住 (Drop, Cover, Hold on)、不推不跑不語原則、地震包清單。
2.  **颱風防災**：固定陽台盆栽與招牌、不前往危險水域觀浪、土石流預警判斷。
3.  **火災逃生**：火場低姿勢爬行、門把燙手不開門、身上著火「停躺滾」、滅火器操作 (拉瞄壓掃)。
4.  **綜合判斷**：處理地震與火災複合災害、瓦斯外洩安全巡檢、高樓層避難策略。

## 🎮 遊戲玩法
1.  **進入任務**：進入關卡前先閱覽「重點摘要」快速複習防災觀念。
2.  **場景分析**：根據畫面的震動或濃煙特效判斷災害類型，並下達正確指令。
3.  **獲取積分**：答對可獲取分數，朝向 100 分「防災守護神」成就邁進。
4.  **檢討與反思**：遊戲結束後，查看「答題回顧」表單，針對**紅字部分**進行重點強化。
